# DogCoach

Mobile App (iOS/Android) auf Basis von [Expo](https://expo.dev) mit Expo Router und TypeScript.

## Start

```bash
npm install
npx expo start
```

Danach in Expo Go, im iOS-Simulator oder Android-Emulator öffnen.

## Struktur

- `src/app/` – Screens (dateibasiertes Routing)
- `src/` – Komponenten, Hooks, Konstanten
- `assets/` – Icons, Splash, Bilder
